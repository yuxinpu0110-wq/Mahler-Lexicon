# Mahler Lexicon v0.1.0 · Windows 免安装版

围绕马勒《第二交响曲》的五乐章聆听与谱面导读工具。

## 下载与使用

1. 在下方 **Assets** 下载 `Mahler-Lexicon-v0.1.0-windows-x64.zip`（约491MiB）。
2. 右键“全部解压”，打开整个解压目录。
3. 双击 **START.cmd**，浏览器自动打开；保留启动窗口即可聆听。

不需要安装 Node.js、FFmpeg、Python，不需要注册或导入录音。适用 Windows 10／11 x64，建议新版 Edge／Chrome。请不要把自动生成的 **Source code.zip** 当作免安装包。
