# Mahler Lexicon 使用指南

这是一份围绕马勒《第二交响曲》的聆听与谱面导读工具。内置五个完整乐章、207页谱面、102段作者导读，以及第四、五乐章的德中英唱词。

## 下载和启动：第一次只需四步

以下四步适用于Windows。Mac用户请下载对应的`macos-arm64.zip`或`macos-x64.zip`并参照[macOS专用指南](https://github.com/yuxinpu0110-wq/Mahler-Lexicon/blob/main/release/macOS使用指南.md)，通过`START.command`启动。

1. 打开 [发行版下载页](https://github.com/yuxinpu0110-wq/Mahler-Lexicon/releases/latest)。
2. 在 **Assets** 中下载名字以 `windows-x64.zip` 结尾的文件，等待下载完整。
3. 右键 ZIP，选择“全部解压”。请解压整个文件夹，不要在压缩包预览窗口内启动。
4. 打开解压后的文件夹，双击 **START.cmd**。浏览器会自动打开；保留启动窗口，开始聆听。

适用 Windows 10／11 x64，建议使用新版 Edge 或 Chrome。无需安装 Node.js、Python、FFmpeg，无需注册账号，也无需导入录音。预留约2GB磁盘空间，以便同时保存下载包和解压后的文件夹。

如果浏览器没有自动打开，把启动窗口显示的 `http://127.0.0.1:47823/` 地址复制到浏览器；端口占用时窗口会给出另一个地址，以实际显示为准。不要直接双击 `app/index.html`。

## 推荐的第一次体验

1. 顶部选择一个乐章，点击“播放”。默认打开第三乐章。
2. 在 **自由检索** 中边听边看下方的谱面、唱词和导读。玻璃小节透镜会跟随估计位置。
3. 点击导读标题旁的小节范围，或正文中的小节链接，可暂停并定位；范围链接会选中一段回听范围。
4. 点击“回听小节”或“回听谱段”，听一次附近内容；上方出现的“仅返回／返回原处继续”可回到出发位置。
5. 试试 **启发探索**：播放时只呈现一句追问。点击整句或“暂停并探索”，再展开赏析、结构、和声、配器。

启发探索的玻璃控制舱包含播放／暂停、前后5秒和进度条。上方弱化的控制区可悬停或用键盘进入，随即恢复可见度。“隐藏提示，连续聆听”只收起提示，不停止音乐。

## 常用操作

- **连续听完整作品**：打开“连续播放”开关，乐章结束后进入下一乐章；关闭时只播放当前乐章。
- **手动看谱**：输入“小节号”，或用前后按钮。点击“跟随播放”恢复自动跟随。
- **放大**：其他乐章的谱面工具栏提供“放大谱面／收起放大”。
- **循环回听**：在下方输入试听起点和终点，点击“循环选区”；“停止循环”恢复正常播放。
- **唱词**：第四、五乐章的声乐段显示唱词，可切换德语、德中或德英；器乐段自动隐藏。
- **本地标记**：“保存当前位置（本地）”保存在当前浏览器。当前是位置列表，不等同于跨设备同步书签。
- **键盘**：Tab 移动焦点，Enter／空格操作按钮或开关，方向键调整进度条；模式单选项支持方向键切换。
- **减少动态**：在系统辅助功能中开启“减少动态效果／动画效果关闭”，光场起伏和透镜弹性会相应减少。

第五乐章合唱初入保持暗夜与顶部微光，后续才逐步进入晨雾、晨光与流金；这是随播放谱位推进的视觉设计，不是程序卡住。

## 退出、离线与更新

- 先暂停，再关闭启动窗口即可停止本地服务；只关闭浏览器标签页不会结束启动窗口。
- 音频、谱面和导读都在下载包内。断网仍可使用；在线字体不可用时自动使用系统字体。
- 服务只监听本机 `127.0.0.1`，不需要管理员权限，不需要把服务开放到局域网。
- 重复启动同一版本会打开已运行的窗口。若端口被其他程序占用，会自动尝试其他本地端口。
- 更新时完整解压新版本并重新启动。浏览器本地记录与浏览器、端口有关；换电脑、换浏览器或清理站点数据会影响本地记录。

## 常见问题

**启动后没有声音**：网页不会自动播放，先点击“播放”；检查系统音量、浏览器标签页是否静音及输出设备。建议使用 Edge／Chrome。若自行导入未知录音，原谱位映射不会套用到该文件。

**启动窗口一闪或提示缺少 runtime**：通常是没有完整解压，或只复制了 START.cmd。请保留整个目录结构；如安全软件隔离了文件，先核对下载来源和发行页提供的校验和，不要随意关闭防护。

**换了音频后不跟谱**：映射绑定项目录音的文件指纹和时长；请恢复项目录音。封装版默认已经内置正确录音。

**小节框与声音稍有偏差**：小节时间与新增四章框选仍是待逐小节校核的估计，可以在进度条上微调回听。第一章作者稿的446–454尚未对应当前谱本，该范围保留阅读、停用音频跳转。

**下载的是 Source code.zip，找不到 START.cmd**：请返回发行页的 Assets，下载 `Mahler-Lexicon-*-windows-x64.zip`，不是自动生成的源码附件。

**使用其他平台**：macOS 13.5及以上可选择Apple芯片或Intel便携包，参照macOS专用指南；Mac包尚未完成实机验收。Linux可按仓库README从源码启动。Windows ARM尚未验证，不应下载Mac的arm64包代替。
