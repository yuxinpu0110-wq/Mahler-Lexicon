## 文件结构

使用 UTF-8 编码，LF 或 Windows CRLF 换行均可。保留开头的三项元信息和两行 `---`：

```markdown
---
format: mahler-lexicon-guides/1
edition: mahler2-imslp415748-ue-scan
movement: 3
---

# 第三乐章 · 聆听导读

## g01 | 先把脚步停住
小节: 1-5
依据: iii-introduction

### 赏析

乐章先给你两下短促的定音鼓和一段停顿。

再听一次，把注意力放在敲击后的空白。

### 结构

这是引子；接下来可对照[第13小节](bar:13)的旋律进入。

### 和声

这里先听音程与节奏怎样建立期待。

### 配器

定音鼓声音的短促起点让两次敲击间的静默更清楚。

### 提示

两次鼓声之间，时间像是停了一下吗？
```

每段均由 `## ID | 标题` 开始。ID（如 `g01`）必须唯一，只能用字母、数字、下划线和连字符；已有ID尽量保留，方便最近提示记录继续指向同一段。标题可以直接修改。

`movement:` 使用1—5，必须与导入时当前乐章一致。`小节:` 使用半角冒号和连字符，如 `小节: 190-211`，两端均包含。当前五份稿件的范围上限分别为454、299、581、67、762；这是稿件范围，不是未接入乐章的总谱核验计数。范围还须处于对应“依据”的声明范围之内。可调整范围或增加条目；重叠时优先显示更短的段落。扩展到现有稿件范围以外时需同步更新校验配置。

## 五个栏目

每段必须各有一次 `### 赏析`、`### 结构`、`### 和声`、`### 配器`、`### 提示`。建议保持这个顺序；不要增加同级标题或在正文插入其他标题。

- **赏析**：给普通听者的可听线索与解释。可以分数段，说明声音发生什么、带来什么变化、再次回听时听哪里。
- **结构**：解释材料的来源、返回、变形与段落作用。提到可对照的本乐章小节时，加上小节链接。
- **和声**：写具体的和声／调性变化及其作用；适当解释术语。不要为了填满栏目虚构和弦。
- **配器**：说明哪些声部在前景或背景，以及音色、音区、密度、延音如何影响听觉。
- **提示**：一行纯文字，建议15—35字，最多90字符。它只在启发探索播放时作为提示出现；不写链接、加粗或换行。

赏析和结构不能为空。暂时没有和声或配器文字时，栏目仍保留，正文写完整的 `（暂缺）`。该文字会被解析为空值，并显示相应缺口。

## 正文可用的 Markdown

支持空行分段、单换行、`**加粗**`，以及小节链接。为保持导入和版面稳定，正文暂不支持列表、表格、图片、代码块、额外标题、HTML和外部网页链接。外部出处统一放在“解读依据”的来源数据中。

```markdown
先听[第13小节](bar:13)，再比较[第348小节](bar:348)。

这一整段可以从[第212—234小节](bar:212-234)回听。

这里的**持续低音**不动，上方和声却改变方向。
```

`bar:13` 始终表示本文件所属乐章的第13小节。五章均有绑定谱本和录音指纹的估计定位，点击链接暂停并定位、更新附近谱面；范围链接还会设置整段试听选区，之后可逐层返回出发上下文。第三章保留小节框；其他四章显示附近整页／系统，时间来自局部编号视窗插值，不能视为精确音头或逐音同步。

稿件声明范围与当前谱本编号分开维护。新导航覆盖第一、二、四、五章的1–445、1–299、1–68、1–764小节。第一章作者稿 g26 声明446–454，仍可完整阅读，但本谱没有对应编号；相关引用不移动音频，不将范围夹到445或猜测换版对应。第四、第五章末尾超出稿件范围的谱位显示暂无导读，不自动复制最后一段。未知本地音频或时长不匹配时停用定位和播放提示，仍可浏览正文。编辑文字不会修改定位或审阅记录。

链接目标须在当前乐章稿件的有效范围内，起点不得大于终点。正文中的普通数字不会自动变链接，新增引用请明确写出上述语法。比如第三乐章文件中提到终乐章第14小节，不能写成 `bar:14`，因为该协议没有跨乐章含义。当前尚无跨乐章小节链接。

第三乐章的启发提示按已有映射随播放位置出现；另外四个乐章在启发模式中可手动展开“这一段的聆听提示”，等待小节映射后再接自动提示，不能用小节数／时长比例代替对齐。

## 检查与常见错误

```sh
npm run content:check
npm test
```

导入会拒绝版本不匹配、重复ID、重复或缺失栏目、超范围小节、未知依据、小节链接错误、HTML，以及多行或过长提示。语法错误尽量报告行号；引用错误会指出导读编号。文件最大1 MB。通过校验的导读不会自动变成正式审阅的音乐事件。
