# Mahler Lexicon v0.1

以马勒《第二交响曲》为范围的播放器与探索工具。已内置项目录音，五个乐章均可直接播放；真实音乐分析仍在核验中。

## 普通用户：下载后直接使用

前往 [GitHub Releases 下载页](https://github.com/yuxinpu0110-wq/Mahler-Lexicon/releases/latest)，在 **Assets** 下载 `Mahler-Lexicon-*-windows-x64.zip`，完整解压后双击 **START.cmd**。这是 Windows 10／11 x64 免安装包，已包含运行环境、五个完整乐章录音和谱面，无需安装 Node.js／FFmpeg，也无需导入音频。

详细操作、推荐体验顺序、离线使用和常见问题见[使用指南](release/使用指南.md)。**“Code → Download ZIP” 是源码，不是免安装包。** 本次免安装附件仅验证 Windows x64；macOS／Linux 可使用下面的源码启动方式。

## 开发者：从源码启动

开发环境需要 Node 24、npm 和 PATH 中可用的 FFmpeg：

```sh
npm ci
npm run dev
```

启动会从项目的 `Recording/` 准备兼容浏览器的无损 FLAC 缓存，打开终端给出的本机地址即可播放。默认第三乐章；25个来源分轨已按顺序无损拼接为5个完整乐章文件，每乐章只有一条连续时间轴，无需选择分轨。

## 构建与最终用户体验

```sh
npm run build
npm run preview
```

`dist/` 是完整静态成品，包含网页、谱例和约364 MiB的5个整乐章FLAC文件。最终用户无需 FFmpeg，也无需另行选择录音。可用支持字节范围请求的静态服务器托管；免安装包已经附带仅监听本机的服务器。不要直接通过 file:// 打开 index.html。

构建前自动准备录音：原始 ALAC 文件保留在 `Recording/`，原件与派生文件分别记录 SHA-256。`recording.json` 和 `catalog.json` 保留原分轨与已审阅事件；`continuous-recording.json` 记录5个新播放文件、来源指纹与准确拼接偏移。应用据此转换事件、页系统和小节时间，声音与谱位身份继续分开。派生缓存 `.local/` 和成品 `dist/` 不进入 Git，构建时仅复制5个连续文件到 dist/audio。

项目所有者已指定该套录音纳入源码并作为成品资源。25个原始音轨及封面随源码保存；免安装成品作为 GitHub Release 附件分发。开发缓存、打包后的大文件与本地工作记录不进入 Git。未启用需要额外服务的 Git LFS。重新封装见[发行说明](release/README.md)。

## 可体验的路径

- 自由检索：Listen Closer 始终可见；播放、拖动、暂停时均可看小节框、浏览导读、选择试听范围及循环。导读里的小节链接可跳转回听，并返回原处。本地标记保存位置；播放器时间为当前完整乐章文件内的秒数。
- 启发探索：播放时音乐厅渐暗，播放条与提示保留舞台光；暂停快速回亮，并在 Listen Closer 查看片段、谱例和解读。支持隐藏提示及会话历史。无核验提示的真实录音目前可无提示连续聆听。
- 乐章内部由同一个音频文件连续播放；开启“连续播放”后在乐章末尾进入下一乐章。单一 audio 元素管理全部声音。
- “交互演示”库提供3个虚构事件、谱例、关联 A/B 与返回路径；合成音频不是马勒作品。
- 页面下方“录音与内容准备”可查看录音版本、两项已核对的真实谱面观察与研究线索；可关联观察、填写谱本位置和试听范围，导出 needs_review 核对草稿。

## 内容状态与边界

正式音频来自用户提供的 Bernstein / New York Philharmonic / 1987 分轨，版本信息与官方目录和文件标签分别登记。第三乐章开头的两条音型已由用户回听审阅确认，对应谱面与试听窗口已进入正式库；审阅记录见 content/real/reviews.json。其余内容不沿用这次审阅。

正式核验事件 2 / 目标10–15；正式提示 2 / 目标6–10。另已接入项目作者完成的五乐章102段导读，分别26 / 13 / 23 / 5 / 35段（第一、二、五乐章采用v2，第三、四乐章保留v1），含四层正文与提示。五乐章均已支持 Listen Closer 中的同步谱面、定位和谱段回听，共207页原谱。第三乐章保留581个小节框；第一、二、四、五乐章有445 / 299 / 68 / 764个估计小节位置，按局部编号视窗与录音对齐定位，显示附近页／系统（47 / 25 / 7 / 65个视图）。第一章g26的446–454在当前谱本中尚无对应编号，保留阅读并停用该范围跳转。新增映射来自离线对齐，保留估计状态，不代表逐音精确跟随。作者稿接入不自动增加已核验事件或引用关系。

本地导入仍可用，文件只留在浏览器，未知文件不套用项目录音映射。书签暂为位置列表，尚无重绑定后跳转；检索范围当前限本乐章可定位事件。跨录音关联跳转仍待完成。

## 第三乐章：波形回听与整章巡览

在 Listen Closer 展开“已核验片段比较”可检索两条已审阅开头片段；点击片段会主动暂停并定位，不需要进入草稿模式：

- 第一组短音型：试听窗口2.0–4.5秒。
- 第二组短音型：试听窗口5.4–7.6秒。

波形区支持点击位置回听5秒、回听选区、循环选区、暂停和数字微调。回听期间保留谱面与波形；仍由单一audio输出。时间轴是完整第三乐章文件内的秒数，选择范围不修改正式事件。点击“仅返回”可逐层回到回听出发位置。

原三分轨巡览已从界面移除。“开发工具 · 小节定位与整章核对”保留完整谱页和小节校对；面向听者的主要入口仍是始终可见的 Listen Closer。完整播放和跟谱不等于整章分析完成。

原分轨波形和3个粗粒度待核验入口保留在研究数据中用于追溯，不再作为听者必须操作的界面。

`npm run test:alignment` 验证正式片段的波形回听、循环、A/B返回及完整乐章上的小节定位；需先build，端口5190可用。历史开头草稿保留用于追溯，不在界面重复显示为待审阅条目。`scripts/refresh-draft-waveform.mjs` 只重建历史能量证据，不改审阅或边界。

## 第三乐章曲谱同步

播放或拖动完整第三乐章时，Listen Closer 中的小节谱面会更新；完整的52个参考视图和48页谱面保存在折叠的开发工具。主动输入小节号、点前后小节或导读目录会暂停并定位到当前乐章文件的**估计时间**；点击“跟随播放”恢复自动谱面跟随。谱页缺失不影响音频。

同步复用跟谱视频视图，并离线对齐到项目纽约爱乐版，不要求更换现有播放源。页/系统映射之外，现已为指定扫描谱的第三乐章建立第1–581小节的稳定位置索引：Listen Closer 在播放中也显示**估计小节框**，选中条目后仍保留；可输入小节号浏览、跟随播放、定位与回听。完整跟谱留在开发工具内。小节位置经过6处栅格检测修正，并与文献关键小节位置交叉检查；小节起止秒数仍是翻页窗口内的估算，停顿、变速和双页显示时尤其需要人工核对。没有逐音光标或完整MusicXML。

第三乐章小节研究卡按编号呈现10条有出处的**待核验**结构、动机、和声及意义线索；听者版使用作者新稿的23段解读。它们不是581条逐小节分析或新增正式条目。“导出当前小节工作包 JSON”提供稳定小节ID、谱面矩形、独立音轨指纹与估计时间、来源观点和个人核验笔记，方便后续向AI提供明确上下文。“针对这个谱段写标注”仍导出整个谱段草稿。完整MusicXML尚未取得，音高、节奏、配器与局部和声未自动符号化。

## Listen Closer 的阅读层次

五个乐章都有“赏析、结构、和声、配器”四个阅读角度，目录和前后段落按钮可浏览102段内容。五章均有估计小节定位，主动选段或点正文引用可暂停并定位，范围链接可选中回听区间。第三章保留小节框，其他章显示附近页／系统。启发模式的问句随匹配录音的实际播放位置显示，手动浏览不生成虚假的提示历史。第四、第五乐章另有独立唱词窗口，随当前声乐段显示。两条已审阅定音鼓事件保留在折叠的“已核验片段比较”，可看谱例、回听和A/B比较。

离线重建方式与依赖见[scripts/sync/README.md](scripts/sync/README.md)。正常启动不需要这些Python依赖。先build，再执行npm run test:sync；需端口5192。参考视频与研究MIDI没有打包进成品。

## 编辑与导入导读 Markdown

当前应用直接读取 [content/listen_guide/v1.0](content/listen_guide/README.md) 内五份作者稿。格式、可编辑字段、小节链接与示例见 [docs/CONTENT_MARKDOWN.md](docs/CONTENT_MARKDOWN.md)。`bar:` 只指当前乐章；第三乐章的 `[第13小节](bar:13)` 会定位并保留返回入口，`[这一段](bar:212-234)` 还会选中整个试听范围。其余乐章也支持匹配录音上的估计小节跳转；稿件编号尚无对应时保留文字浏览，不猜测音频位置。旧 `content/real/listening-guides.md` 保留作兼容格式样例，不再作为运行时正文。

`npm run dev` 后先选择相应乐章，展开下方开发工具，点击“导入解读 Markdown”。导入按当前乐章校验并在本浏览器分别保存，错误乐章文件不会覆盖；失败时维持原内容。“下载当前导读 Markdown”取回当前乐章实际使用的版本，“恢复项目内置导读”只清除当前乐章的覆盖。若要随仓库交付，保存回作者目录中的对应Markdown文件并重新构建；生产版不显示导入按钮。旧版第三乐章的本地覆盖不会自动盖住此次新作者稿。

## 五章小节定位与启发提示

在 Listen Closer 输入小节号，或点击导读目录、正文中的小节引用，可以暂停并定位到附近；范围引用同时设置完整回听选区。上方“仅返回／返回原处继续”可逐层恢复出发位置、模式和阅读栏目。“跟随播放”恢复谱面及正文自动跟随。启发探索在匹配录音上显示当前位置的一条作者提示，点击后暂停探索，隐藏提示仍可连续聆听。

新增四章映射为局部编号视窗内插值及DTW迁移的估计值，不是精确音头。第一章本谱止于445；作者g26的446–454保留完整正文，但暂不跳转。第四章68与第五章763–764没有作者导读时显示空状态。维护方法见 `scripts/sync/README.md`；正常启动无需重新运行Python或OCR。

## 五乐章视觉与正文链接

界面采用五章色板与玻璃控件：第二章为暖纸色，第一／三／四章和第五章前段为深色，第五章实际播放进入估计第472小节后开始分层破晓，合唱初入保持暗夜。桌面并排阅读谱面与正文，窄屏纵向；谱面工具栏、小节链接、德中英唱词和返回入口均保留。启发播放时正文先收束，点击“暂停并展开深度解析”或提示可进入四个阅读角度。

小节引用支持加粗文字内的链接；录音尚在载入时点击，会在文件核对与载入完成后定位，切换乐章则取消。未知录音仍不能套用映射。Google字体请求失败时使用系统字体。听众操作见[使用指南](release/使用指南.md)。


五章主谱面均有透明玻璃小节透镜：移动时前缘先行、后缘轻微粘滞拉伸，换行轻缩再舒展；只提亮音符，不加模糊，折射高光随各章主题变化。谱面继续与背景融合，翻页等图片解码后交叠淡入。新增四章的框选与时间仍待逐小节校核，生成方法见`scripts/sync/README.md`；动效回归运行`npm run test:score-motion`。

第五章按实际录音估计谱位分层日出：472–511只亮顶部微光，512–579进入玫瑰晨雾，580–639漫向象牙晨光，640–762渐至流金，合唱初入不会刷白。低／中／高频从同一播放音源读取，重阻尼后驱动光域、追问背光与玻璃边缘；分析不可用时保留原生播放并慢呼吸回退。启发播放采用无边框悬浮追问与居中胶囊控制舱，上方非核心区域轻暗、悬停或键盘进入恢复。系统减少动态时关闭音频光场起伏，破晓直接对齐当前位置。界面验收运行`npm run test:atmosphere`。
